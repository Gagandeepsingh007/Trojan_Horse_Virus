# Trojan Horse Virus

### This is a trojan horse virus, here the screenshotSender.py is the virus code which in injected into the main.py file and it sends the screen shots of the user's computer to a URL which is generated using ngrok
```
1. User opens the Mario Super Bros. game written in python.
2. The game is injected with a code which sends the screen shot of user's computer without the user's consent and knowledge.
3. The screen shot may contain sensitive information like password of personal pictures which can be used with malicious intent.
```
